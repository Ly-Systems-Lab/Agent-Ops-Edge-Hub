# 设备插件契约

> **一句话**：核心不认识任何设备；每台设备是一个自包含目录。
> 接一台新设备 = 复制一个目录、填六处、加一段 ACL，**核心代码不动**。

---

## 一 · 边界怎么划

| | 核心 | 设备插件 `devices/<name>/` |
|---|---|---|
| 认不认识具体设备 | **不认识** | 只认识自己 |
| 提供什么 | 总线、生命周期、回执配对、配置与库、告警产出 | 主题、指令解析、回执渲染、凭据、单元 |
| 改它影响谁 | 所有设备 | 只有它自己 |

**判据**：删掉一个设备目录，其余链路照常跑；加一个设备目录，核心一行不改。

---

## 二 · 核心提供什么

- MQTT 连接 / 重连退避 / 回调异常兜底
- 企微长连接基类（订阅、心跳、`save_chat`、`send_markdown`、被动回复）
- **回执配对**：`pending` 表 + 超时扫描 + 无 pending 时改推默认会话
- 配置读取（env > `.env` > SQLite > 默认）与库连接
- 告警产出（`hub/alert/#`）

**核心不提供**：任何设备的指令集、任何设备的报文格式、任何设备的名字。

---

## 三 · 设备目录必须提供什么（六处）

| # | 项 | 例 |
|---|---|---|
| 1 | 主题 | `TOPIC = "hub/command/<name>"` / `ACK_TOPIC = ".../ack"` |
| 2 | 指令解析 | 文本 → `(cmd, arg)` |
| 3 | 回执渲染 | payload → 一句人话 |
| 4 | 凭据键 | `<NAME>_WECOM_BOT_ID` / `_SECRET` |
| 5 | 推送目标键 | `wecom_chat_id_<name>` |
| 6 | systemd 单元 + ACL 片段 | 各自目录内 |

**六处都在你自己的目录里；核心一行不改。** 需要改第七处，说明边界划错了 —— 先改边界，别在插件里打补丁。

> 想连**验收闸门**也自动验你这台设备？可选加一个 `selfcheck.sh`（见「三之二」）——
> 那是加在你目录里的文件，不是改核心。

---

## 三之二 · 可选：验收自检钩子

`acceptance_s9.sh` 启动时 source `devices/<name>/selfcheck.sh`（有就加载，没有就跳过），
再按**目录名**推出函数名去调用 —— **核心里没有一个设备名**。

| 钩子 | 作用 | 不写会怎样 |
|---|---|---|
| `<name>_selfcheck_net` | 返回 0/1，计入「网络」档 | 网络档少这一项 |
| `<name>_selfcheck_device` | 返回 0/1，计入「设备在线」档 | 该档显示「未覆盖」 |
| `<name>_selfcheck_hint` | 只打提示，不参与判据 | 少一段提示 |
| `<name>_baseline` | 打 `KEY=value` 行，写进 baseline 文件 | baseline 少几个键 |

**不写也完全能跑**，只是验收闸门不会替你验这台设备。
钩子被 source 进同一个 shell，可直接用 `log()` / `$DIR` / `$BASE_FILE` / `$LOG`。
目录名只允许 `a-z0-9_`（函数名由它拼出来）。

## 四 · 传输方式：是选型，不是架构

**架构主张只有一条：一切皆插件。** 传输协议按设备资源选：

| 设备形态 | 推荐 | 理由 |
|---|---|---|
| 低性能 MCU | **HTTP**（被推） | 少一层长连接与重连状态机，固件里省下的正是最紧的那部分 |
| 能跑 MQTT 的设备 | **MQTT** | 拿到 QoS 1、按主题收窄的 ACL、与其余设备同一套总线 |
| 需要即时双向的 | **MQTT** | HTTP 只能被推，设备侧发不出「我现在有事」 |

MQTT 强行套到低性能 MCU 上**也能做**，只是不推荐 —— 那是资源账，不是架构账。

⇒ **一台走 HTTP 的设备当插件，和一台走 MQTT 的设备当插件，在架构上是同一件事。**
把「不做通用路由」读成「所以做不到插件化」，是读反了。

## 五 · 模板

新设备从 `devices/_template/` 复制：

```bash
cp -a devices/_template devices/<name>
# 填上面那张表的六处；systemd 单元改名；ACL 加一段 user <name>
```

模板里只有骨架和注释，**不含任何具体设备的痕迹**。
